# 🛞 ШинаСервис — онлайн-запись на шиномонтаж

Самодостаточный одностраничный сайт автосервиса: публичная онлайн-запись,
админ-панель и панель сотрудников с посменным графиком. Один HTML-файл без
сборщиков и зависимостей — данные хранятся в `localStorage` браузера.

## Возможности

### Публичная часть
- Каталог услуг с ценами и длительностью, запись в 3 шага (услуги → дата/время → контакты);
- Слоты с учётом рабочего графика, количества постов и перерыва 15 минут между записями;
- «Мои записи» по номеру телефона с возможностью отмены;
- Уведомления клиенту: экран успеха с кнопками «📅 В календарь» (ICS-файл-напоминание), «💬 WhatsApp» и «✈️ Telegram» с готовым текстом визита.

### Админ-панель (`admin123` по умолчанию)
- Дашборд: записи на сегодня, новые, выручка за месяц, график загрузки за 7 дней, смены мастеров;
- Записи: фильтры (статус, период, мастер, поиск), смена статусов, редактирование, удаление, экспорт CSV/JSON, ручная запись клиента;
- Источник каждой записи — «онлайн» или «телефон» — в таблице, карточке записи и CSV-выгрузке;
- Статистика на главной: четыре цифры и подписи в шапке сайта редактируются в «Настройках» (пустые пункты скрываются);
- Услуги: добавление, редактирование, скрытие от клиентов;
- Расписание: рабочие дни, часы, интервал слотов, посты, праздничные дни;
- Настройки: данные сервиса, смена пароля, резервные копии JSON.

### Панель сотрудника (вход по ПИН-коду)
- Два сотрудника работают посменно — чередуются через день (дата старта и порядок настраиваются в админке);
- Записи автоматически закрепляются за мастером по дате визита; админ может назначить вручную;
- Сотрудник видит **только свои** записи и может: подтвердить, завершить, изменить (дата, время со свободными слотами, услуги с пересчётом суммы, контакты), отменить;
- **Запись по звонку**: кнопка «+ Записать клиента» — форма с датой, свободными слотами и выбором мастера, включая смену коллеги (запись уходит в его панель с уведомлением);
- **Уведомления о новых записях**: бейдж «🔔 Новые» с числом непросмотренных записей, всплывающий тост при появлении новой записи (в том числе созданной клиентом в другой вкладке) и фильтр «Непросмотренные»;
- Выручка за **день / неделю / месяц** своей работы + счётчик записей.

### Мобильная версия
- Полная адаптация: карточки вместо широких таблиц, полноэкранные модалки,
  крупные тап-таргеты, поля без автозума на iOS, горизонтального скролла нет.

## Демо-доступ

| Роль | Где входить | Пароль / ПИН |
|---|---|---|
| Администратор | кнопка «Админка» в шапке | `admin123` |
| Сотрудник Сергей | футер → «Панель сотрудника» | `1111` |
| Сотрудник Андрей | футер → «Панель сотрудника» | `2222` |

Пароли и ПИН-коды меняются в админке. Это демо: они хранятся в `localStorage`
открытым текстом — для боевого использования нужна серверная авторизация.

## Структура

```
index.html          — собранный сайт (открывается двойным кликом)
src/
  site_parts/       — исходники по частям (стили, HTML, JS)
  build_site.py     — сборка: python3 src/build_site.py src/site_parts index.html
  check_site.py     — быстрая проверка: JS-синтаксис, ссылки на id, мусорные строки
```

## Локальный запуск

Открыть `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Деплой на GitHub Pages

1. Settings → Pages → Source: `Deploy from a branch`;
2. Branch: `main`, папка `/ (root)` → Save;
3. Сайт будет на `https://<логин>.github.io/<репозиторий>/`.

## Хранение данных

Все данные (записи, услуги, настройки, сотрудники) лежат в `localStorage`
браузера на устройстве пользователя. Резервная копия — «Настройки → Экспорт
JSON» в админке. Сброс браузера = сброс данных.
