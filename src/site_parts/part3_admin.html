Данные автосервиса

Статистика на главной

Четыре цифры в шапке сайта, под кнопками «Записаться». Значение обязательно, подпись — нет; пустое значение скрывает пункт.

Уведомления клиентам

При подтверждении или отмене записи клиенту автоматически уходит SMS или сообщение в мессенджер MAX — клиент ничего не выбирает, канал задаётся здесь. Для реальной отправки укажите URL шлюза (POST JSON: phone, text, channel); без шлюза тексты сохраняются в журнале карточки записи.

Сотрудники и смены

График смен

Активные сотрудники чередуются через день, начиная с даты старта: в первый день работает выбранный ниже сотрудник. Деактивированный сотрудник пропадает из ротации, его записи остаются.

Данные (резервная копия)

Все записи хранятся в браузере (localStorage). Делайте резервную копию JSON и переносите её на другое устройство.

Безопасность

Сброс данных

Полностью удалит все записи, услуги и настройки и вернёт демо-состояние. Действие необратимо.
